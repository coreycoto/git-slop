# git-slop v0.8.1

`v0.8.1` is a hotfix release for the `git slop compare` surface shipped in
`v0.8.0`.

## Fixes

- Fixed `git slop compare` crashing on real schema-3 reports when an overlay
  family value is `null`.
- Null or non-mapping overlay family values are now treated as absent overlay
  evidence when computing strongest overlay pressures.
- Added regression coverage for comparing a report record with null overlay
  family values.

## Boundaries

This release does not change detector scoring, report generation, check
semantics, or the compare payload schema. It only makes downstream comparison
more tolerant of existing report shapes.
