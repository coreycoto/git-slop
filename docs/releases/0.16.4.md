# Git Slop 0.16.4

Version 0.16.4 fixes the JavaScript and TypeScript verification false positives
reported in [issue #147](https://github.com/coreycoto/git-slop/issues/147).

Numbered improvements: **1**.

1. Keep verification gaps visible when source code calls ordinary methods such
   as `RegExp.test()` or `String.split()`. Detect complete test-call identifiers
   in executable source instead of raw substrings, ignoring member calls,
   comments, quoted strings, template text, and regular-expression literals.
   Recognize real `describe`, `test`, and `it` definitions across normal
   whitespace and comment formatting, including `only` and `skip` modifiers.
   Regression coverage scans tracked, commentless JavaScript and TypeScript
   through the real CLI in compact and standard profiles, checking both inline
   flags, mapping confidence, rationale, evidence status, and the verification
   gap. The original three-file reproduction retains its hotspot scores.

This patch adds no CLI commands, configuration keys, report fields, or Action
inputs or outputs. Verification remains an advisory overlay; stable hotspot
scoring and CI policy are unchanged.
