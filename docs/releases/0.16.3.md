# Git Slop 0.16.3

Version 0.16.3 fixes the Drizzle Kit metadata classification reported in
[issue #145](https://github.com/coreycoto/git-slop/issues/145).

Numbered improvements: **1**.

1. Recognize Drizzle Kit's `_journal.json` and numeric `*_snapshot.json`
   filenames directly under `drizzle/meta/` as generated migration history,
   including `packages/example-db/drizzle/meta/0001_snapshot.json`. Keep byte,
   token, and size evidence visible in compact and standard reports, while
   routing findings to the observation feed as generator-source investigations
   instead of editable-source interventions. Preserve ordinary source files,
   migration SQL, vendor precedence, and explicit classification overrides.
   Regression coverage exercises a tracked, commentless JSON snapshot through
   the real CLI and verifies that scanning leaves its contents unchanged.

This patch adds no CLI commands, configuration keys, report fields, or Action
inputs or outputs. It uses the existing generated-file classification and
investigation contracts.
