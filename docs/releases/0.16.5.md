# Git Slop 0.16.5

Version 0.16.5 fixes report review gaps and consolidates dependency, plugin, and
maintainer updates merged since 0.16.4.

Numbered improvements: **8**.

1. Explain compact-report paths accurately. A path retained in the complete
   index but omitted from detailed evidence now gets a standard-report recovery
   instruction. Truly absent paths retain their missing-record error; explain
   does not invent metrics or rescan the repository (#149).
2. Show real score movements in default compare text. Rank increases and
   decreases before applying `--top`, so evidence-only changes cannot hide
   them. Preserve changed-only queue output and the existing JSON, YAML, and
   NDJSON pagination (#153).
3. Preserve report identifiers across the BLAKE2 update. Keep the same 16-byte
   digest over NUL-terminated parts and six-byte public identifier prefix,
   with independent golden vectors for empty parts, boundaries, ordering, and
   UTF-8 (#165).
4. Consolidate Rust dependency updates: BLAKE2 0.11, Zstandard 0.14, jsonschema
   0.58.5, and its resolved 0.58.6 family packages. Keep the public crate's Rust
   1.85 floor and the private maintainer workspace's separate dependency graph
   (#165, #166).
5. Keep Dogfood failures reviewable. Render bounded, escaped comparison context
   before acceptance verification and point the failure summary to exact source
   IDs and the existing complete report/comparison artifact. Preserve verifier
   failure status, artifact retention, and the acceptance policy (#152).
6. Replace the retired Python maintainer runtime with private Rust adapters and
   the pinned native gh-steward 0.4.1 tool. Execution State preparation and
   approved application use separate manual dispatches with retained plan and
   journal evidence. Automatic dependency publication remains disabled pending
   complete native ownership in #157; historical unknown operations remain held
   (#154).
7. Scope maintainer acquisition and credentials to their intended steps. Verify
   the native tool's source, version, checksums, and attestations, authenticate
   hosted attestation reads, and isolate offline fixtures from hosted defaults.
   Privileged workflows retain trusted-base inputs and deliberate mutation
   boundaries (#154, #164).
8. Improve portable plugin guidance and maintainer organization. Add the phased
   refactor handoff, adopt plugin-owned maintenance roles with repository
   overlays, and group report lookup, compare presentation, and Dogfood tests by
   purpose within their existing harnesses (#151, #163, #167).

The public CLI gains no commands or options in this patch. Report schemas,
machine pagination, stable hotspot scoring, and Action inputs and outputs retain
their contracts. The Action remains advisory by default. Public advisor
inference remains disabled by its existing release gate.

Use version-pinned installation examples after 0.16.5 is published and verified
on the requested distribution surface.
