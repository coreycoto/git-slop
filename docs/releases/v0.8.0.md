# git-slop v0.8.0

`v0.8.0` completes the V2/V3 follow-through after the initial local-first
detector release.

## Highlights

- Added schema-v2 `git slop explain` and `git slop plan` payloads with clearer
  deterministic evidence summaries, bounded plan slices, and preview-only
  backlog handoff metadata.
- Added prompt-pack-only local model handoff for `explain` and `plan`; the CLI
  writes deterministic local prompt files but does not invoke models, call a
  provider, or rescore detector truth.
- Added read-only V3 downstream surfaces:
  - `git slop compare` for report trend comparisons
  - `git slop sarif` for SARIF 2.1.0 export
  - `git slop refactor-preview` for preview-only bounded maintainer steps
- Added editor-adjacent artifact recipes for consuming SARIF, plan JSON, and
  refactor-preview JSON without an editor extension, language server, watcher,
  hosted service, or model runtime.
- Tuned Codex-powered governance workflows to reduce unnecessary model spend by
  using cheaper explicit models, narrower triggers, and deterministic preflight
  checks.

## Boundaries

This release preserves the detector contract:

- no detector rescoring
- no overlay score inflation
- no autonomous code mutation
- no GitHub mutation from `git-slop`
- no changes to `priority_score`, `priority_band`, `context_band`, or
  `git slop check` semantics
