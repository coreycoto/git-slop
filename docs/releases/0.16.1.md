# Git Slop 0.16.1

Version 0.16.1 is a fail-closed advisor safety correction. It preserves all
deterministic detector, report, policy, and provider-free context behavior
while preventing Git Slop from implicitly selecting or contacting Ollama or
another model provider.

Numbered improvements: **79**.

1. Require `--infer` before any provider configuration, probe, or request can
   run.
2. Remove public provider, endpoint, canonical-model, and runtime-model
   defaults; inference identities must be supplied explicitly.
3. Make provider-free JSON context the stable `advise` default and disable
   public inference while the checked-in benchmark recommendation is `defer`.
4. Add a fail-closed capacity preflight covering model bytes, conservative peak
   memory, physical memory, available-memory reserve, and current swap.
5. Add continuous available-memory and swap-growth watchdogs that abort a
   provider request and terminate the benchmark matrix without retry.
6. Remove every provider/model/endpoint default from the maintainer benchmark.
7. Remove benchmark runtime management, including `ollama stop`; Git Slop never
   installs, starts, stops, unloads, discovers, or downloads Ollama or models.
8. Require a separately provisioned dedicated benchmark host and hard-reject
   the recorded 16-GB M2-class capacity.
9. Add an executable advisor release gate and run its distribution validation
   from release preparation; only `ship` may enable public inference.
10. Refuse non-loopback providers until an authenticated TLS transport exists;
    remove the plaintext remote escape hatch.
11. Require and print explicit model-size and peak-memory evidence plus
    `--confirm-resources` before benchmark provider contact.
12. Add a zero-data connection probe, separate connection and total-request
    timeouts, phase progress, and explicit Ctrl-C cancellation guidance.
13. Add an OOM recovery, exact-model removal, Homebrew uninstall, and
    post-recovery verification runbook without unsafe broad deletion commands.
14. Validate context format before report access or cache writes and choose JSON
    automatically when inference is absent.
15. Align README, advisor, architecture, vision, benchmark, troubleshooting,
    release, CLI-reference, and checklist claims with the `defer` decision.
16. Hide disabled inference, provider, model, resource, timeout, and mock
    controls from the stable `advise --help` surface.
17. Make `doctor` report that provider-free context is available, no model is
    required for ordinary use, and public inference is disabled.
18. Add `cargo xtask advisor-capacity`, which measures only host memory and
    swap and proves in its receipt that it read no report and contacted no
    provider.
19. Reject a host before provider contact when more than 256 MiB of swap is
    already in use.
20. Enforce canonical model, model-size, peak-memory, physical-memory,
    available-reserve, and swap limits as hard runtime and harness floors even
    if the checked-in gate is weakened.
21. Require every provider response to identify the exact served model and a
    normal stopped completion rather than accepting truncated output; terminate
    the benchmark immediately on served-model identity drift.
22. Complete `Content-Length` and chunked responses without waiting for a
    keep-alive socket to close, while rejecting conflicting response framing.
23. Drain benchmark child stdout and stderr concurrently so a full pipe cannot
    deadlock resource monitoring or timeout enforcement.
24. Parse Cargo feature declarations structurally so comments or formatting
    cannot spoof default-feature and benchmark-feature isolation checks.
25. Return every capacity failure as a stable blocker with actual bytes,
    comparison direction, limiting bytes, and a human message.
26. Publish the strict `advisor-capacity-1` contract and expose it through
    `git slop schema advisor-capacity`.
27. Make human capacity output show the complete model, peak-memory,
    physical-memory, available-memory, and swap requirement contract.
28. Retain at most 8 MiB from each benchmark child stream while continuously
    draining it, and terminate the matrix if either boundary is crossed.
29. Reject oversized declared HTTP bodies, unsupported transfer/content
    encodings, non-JSON success responses, and trailing chunk data before
    provider-envelope validation.
30. Format IPv6 loopback Host headers correctly and give invalid or zero ports
    stable endpoint diagnostics.
31. Split provider HTTP transport from policy-message and response-validation
    logic to restore focused module context headroom.
32. Keep release-gate evaluation out of provider-free context construction and
    defer provider configuration and probing until report, policy, and bounded
    context validation have completed locally.
33. Add a regression listener proving a locally invalid request cannot contact
    even an explicitly configured loopback provider.
34. Remove endpoint paths and arbitrary provider metadata from stored
    provenance, allowlist only numeric token counts and bounded fingerprints,
    and omit HTTP error bodies from diagnostics.
35. Apply one connection deadline across every resolved loopback address
    instead of granting a fresh timeout to each address.
36. Reject runtime model and label values that are not bounded,
    privacy-safe identifiers before provider contact.
37. Replace the permissive advisor benchmark schema with a strict nested
    contract for prepare-only, complete, incomplete, finalized, and release
    evidence states.
38. Validate every prepare, aggregate, incomplete, and finalized benchmark
    result against the published schema before writing it.
39. Accept maintainer ratings only through the finalization command; revalidate
    the input result, hashes, thresholds, exact corpus matrix and repository
    bindings, recommendation, and every derived automatic gate without
    rerunning inference.
40. Refuse already finalized evidence, require the existing decision report to
    match its JSON evidence exactly, and regenerate it from the finalized result
    before changing either output.
41. Replace `results.json` and `decision.md` as one rollback-safe pair, using
    synchronized new files and restoration backups on partial failure.
42. Use a new mode-0700 temporary benchmark workspace with distinct per-sample
    artifact names, and split preparation, evidence binding, decision rendering,
    aggregation, persistence, and finalization into focused maintainer modules.
43. Bound every report, context, artifact, schema, ratings, and benchmark input
    read before parsing so oversized private evidence fails closed.
44. Apply one total deadline across benchmark execution phases and turn stalled
    resource-monitor heartbeats into explicit terminal safety failures.
45. Supervise benchmark children as process groups with interrupt propagation,
    TERM-to-KILL escalation, prompt reaping, and cleanup on every error path.
46. Drain child stdout and stderr concurrently while enforcing independent
    retained-byte ceilings so neither pipes nor maintainer memory can grow
    without bound.
47. Preserve structured child error codes and classify provider, validation,
    timeout, output, interrupt, and resource failures without parsing arbitrary
    private diagnostics.
48. Bind benchmark evidence to a clean harness revision and a capability-bearing
    candidate binary built from that exact revision.
49. Recompute advice-artifact verdicts, references, citations, and warnings
    independently before benchmark evidence is accepted.
50. Give every benchmark sample a distinct private path inside a mode-0700
    workspace so retries and matrix cells cannot reuse artifacts.
51. Enforce bounded command output when collecting Git, build, and benchmark
    provenance rather than trusting subprocess output size.
52. Treat unavailable resource measurements and monitor state as fail-closed
    request aborts with stable safety codes.
53. Add provider-free lifecycle regression coverage for bounded success,
    nonzero exits, deadlines, forced termination, and output floods.
54. Persist advice under owner-private directories and files, rejecting symbolic
    roots and reporting unsafe permissions.
55. Replace `advice.json` and Markdown as a synchronized, fsynced pair and
    recover interrupted `latest` transactions before subsequent writes.
56. Revalidate cached advice semantics, policy matrices, references, aggregate
    verdicts, citations, and warning parity instead of trusting stored flags.
57. Extend `doctor` with advice-state recovery, retained-run, byte, permission,
    staleness, and current-report diagnostics.
58. Make `prune` preview and apply detector and advice retention together while
    always preserving the mutable `advice/latest` pointer.
59. Publish and runtime-validate a strict advisor-threshold contract so schema
    and deserialization cannot drift.
60. Write benchmark JSON and decision Markdown through a recoverable two-file
    transaction that restores both originals after partial replacement.
61. Self-digest every benchmark sample and bind it to its immutable source
    advice artifact before review evidence is created.
62. Generate blinded review artifacts plus a shareable opaque index and a
    withheld manifest that maps each review ID to exact private evidence.
63. Require two independent reviewers and complete multi-repetition coverage,
    with ratings bound to source-result and review-manifest digests.
64. Make finalization preview-only by default, require explicit `--apply`, write
    new immutable outputs, and never overwrite completed source evidence.
65. Publish strict operation receipts that distinguish retained, not-retained,
    and inapplicable review evidence without leaking private paths.
66. Lead human advice with a decision summary, candidate dispositions, next
    steps, citations, assumptions, missing evidence, and retention warnings.
67. Centralize benchmark status, termination, metrics, gates, recommended
    configuration, and recommendation in one typed derivation engine.
68. Split benchmark orchestration, child supervision, review, derivation,
    evidence, persistence, and finalization into explicit Rust modules.
69. Add an end-to-end no-provider child fault matrix covering success, ordinary
    failure, timeout, TERM resistance, stdout flood, and stderr flood.
70. Preserve the Rust 1.85 minimum toolchain when constructing and monitoring
    resource guards.
71. Stabilize cross-platform provider diagnostics and report-schema fixtures so
    native lanes evaluate the same public contracts.
72. Classify empty provider closes as `provider_unavailable` consistently across
    supported operating systems.
73. Bind reviewed Dogfood regression acceptances to exact base/head revisions,
    report digests, severity, scores, and expiry.
74. Run Dogfood on the exact pull-request head so a trusted-base checkout cannot
    accidentally validate different code.
75. Make the disconnect transport fixture consume the complete request before
    closing, eliminating the macOS timing race seen after PR 128 merged.
76. Normalize read/write socket setup failures as privacy-safe
    `provider_unavailable` diagnostics instead of exposing raw OS errors.
77. Backfill the complete post-0.16.0 advisor and CI ledger so release notes no
    longer stop before the merged follow-on work.
78. Keep the changelog marked `Unreleased` during development and require a real
    publication date only at the protected release boundary.
79. Validate the declared release-note count, contiguous numbering, version
    heading, and changelog link during release preparation and distribution
    checks.

No model or provider is required for ordinary Git Slop use.
