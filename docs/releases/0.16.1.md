# Git Slop 0.16.1

Version 0.16.1 is a fail-closed advisor safety correction. It preserves all
deterministic detector, report, policy, and provider-free context behavior
while preventing Git Slop from implicitly selecting or contacting Ollama or
another model provider.

1. Require `--infer` before any provider configuration, probe, or request can
   run.
2. Remove public provider, endpoint, canonical-model, and runtime-model
   defaults; inference identities must be supplied explicitly.
3. Make provider-free JSON context the stable `advise` default and disable
   public inference while the checked-in benchmark recommendation is `defer`.
4. Add a fail-closed capacity preflight covering model bytes, conservative peak
   memory, physical memory, available-memory reserve, and current swap.
5. Add continuous available-memory and swap-growth watchdogs that abort a
   provider request and terminate the benchmark matrix without retry.
6. Remove every provider/model/endpoint default from the maintainer benchmark.
7. Remove benchmark runtime management, including `ollama stop`; Git Slop never
   installs, starts, stops, unloads, discovers, or downloads Ollama or models.
8. Require a separately provisioned dedicated benchmark host and hard-reject
   the recorded 16-GB M2-class capacity.
9. Add an executable advisor release gate and run its distribution validation
   from release preparation; only `ship` may enable public inference.
10. Refuse non-loopback providers until an authenticated TLS transport exists;
    remove the plaintext remote escape hatch.
11. Require and print explicit model-size and peak-memory evidence plus
    `--confirm-resources` before benchmark provider contact.
12. Add a zero-data connection probe, separate connection and total-request
    timeouts, phase progress, and explicit Ctrl-C cancellation guidance.
13. Add an OOM recovery, exact-model removal, Homebrew uninstall, and
    post-recovery verification runbook without unsafe broad deletion commands.
14. Validate context format before report access or cache writes and choose JSON
    automatically when inference is absent.
15. Align README, advisor, architecture, vision, benchmark, troubleshooting,
    release, CLI-reference, and checklist claims with the `defer` decision.
16. Hide disabled inference, provider, model, resource, timeout, and mock
    controls from the stable `advise --help` surface.
17. Make `doctor` report that provider-free context is available, no model is
    required for ordinary use, and public inference is disabled.
18. Add `cargo xtask advisor-capacity`, which measures only host memory and
    swap and proves in its receipt that it read no report and contacted no
    provider.
19. Reject a host before provider contact when more than 256 MiB of swap is
    already in use.
20. Enforce canonical model, model-size, peak-memory, physical-memory,
    available-reserve, and swap limits as hard runtime and harness floors even
    if the checked-in gate is weakened.
21. Require every provider response to identify the exact served model and a
    normal stopped completion rather than accepting truncated output; terminate
    the benchmark immediately on served-model identity drift.
22. Complete `Content-Length` and chunked responses without waiting for a
    keep-alive socket to close, while rejecting conflicting response framing.
23. Drain benchmark child stdout and stderr concurrently so a full pipe cannot
    deadlock resource monitoring or timeout enforcement.
24. Parse Cargo feature declarations structurally so comments or formatting
    cannot spoof default-feature and benchmark-feature isolation checks.
25. Return every capacity failure as a stable blocker with actual bytes,
    comparison direction, limiting bytes, and a human message.
26. Publish the strict `advisor-capacity-1` contract and expose it through
    `git slop schema advisor-capacity`.
27. Make human capacity output show the complete model, peak-memory,
    physical-memory, available-memory, and swap requirement contract.
28. Retain at most 8 MiB from each benchmark child stream while continuously
    draining it, and terminate the matrix if either boundary is crossed.
29. Reject oversized declared HTTP bodies, unsupported transfer/content
    encodings, non-JSON success responses, and trailing chunk data before
    provider-envelope validation.
30. Format IPv6 loopback Host headers correctly and give invalid or zero ports
    stable endpoint diagnostics.
31. Split provider HTTP transport from policy-message and response-validation
    logic to restore focused module context headroom.

No model or provider is required for ordinary Git Slop use.
