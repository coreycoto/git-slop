# Git Slop 0.16.2

Version 0.16.2 consolidates dependency maintenance and includes the advisory
Action surface-area work merged after the immutable 0.16.1 crates.io package.
Version 0.16.1 retains its original published source identity.

Numbered improvements: **6**.

1. Refresh the CLI, shell-completion, compression, and error dependencies:
   `clap` 4.6.7, `clap_complete` 4.6.11, `clap_complete_nushell` 4.6.2,
   `flate2` 1.1.10, and `thiserror` 2.0.21, with their verified lockfile updates.
2. Upgrade `tiktoken-rs` to 0.12.1, bringing the upstream tokenizer refresh
   while preserving Git Slop's configured tokenizer behavior and Rust 1.85
   minimum. Tokenizer, detector, and provider-free context regression tests
   remain part of release qualification.
3. Upgrade the four maintainer workflows to the immutable Codex Action 1.12
   pin. Configure noninteractive approval in their trusted temporary config
   instead of passing the profile selectors rejected by protected Action runs,
   and enforce that compatibility in the workflow validator and regression tests.
4. Add an experimental, path-based surface-area ledger to the GitHub Action
   job summary. Its separate dimensions support review without a composite
   score or enforcement gate; unavailable ledger evidence stays advisory.
5. Fix critical maintenance-pressure findings being rejected by the report's
   own schema (#143). Preserve scores and the `critical` band in every report
   index, synchronize the published schema, and verify freshly generated compact
   and standard reports with `report validate`, `health`, and `explain` without
   rescanning. A real-CLI Action regression verifies one analysis, report and
   summary publication, and advisory policy exit 0 despite critical findings.
6. Accept the bundled `schemas/index.json` catalog in the Action installer's
   exact archive layout. Exercise both Unix and Windows archives with the
   packaged catalog while retaining rejection of unexpected files and arbitrary
   unversioned schemas. This fixes the archive-layout mismatch that prevented
   the 0.16.1 draft from completing installer qualification.

The normal release workflow qualifies the exact crate, all seven native
targets, the composite Action, and the generated Homebrew Formula before
publication. Public package-manager consumers remain bound to the same
version, source revision, and crate digest.
