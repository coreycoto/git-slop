## `git-slop man`

Generate the roff manual from the live Clap command tree

**Usage**

```text
Usage: man [OPTIONS]
```

| Argument | Value | Default | Constraints | Description |
| --- | --- | --- | --- | --- |
| `--output` | `OUTPUT` | `-` | - | Destination file. Defaults to stdout |

**Example**

```sh
git slop man --output man/git-slop.1
```
