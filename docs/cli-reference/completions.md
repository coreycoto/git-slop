# Git Slop CLI Reference: `completions`

Generated from the live Clap command tree.

## `git-slop completions`

Generate shell completion source

**Usage**

```text
Usage: completions <SHELL>
```

| Argument | Value | Default | Constraints | Description |
| --- | --- | --- | --- | --- |
| `shell` | `SHELL` | `-` | required; values: bash, zsh, fish, powershell, nushell | Shell whose completion source should be generated |

**Example**

```sh
git slop completions bash
```
