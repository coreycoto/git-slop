# Git Slop Sponsors

Git Slop is open, local-first developer tooling. Sponsorship supports releases,
documentation, compatibility work, and ongoing maintenance.

[Become a sponsor](https://github.com/sponsors/coreycoto).

## Recognition policy

- Only active sponsors who choose public recognition are listed.
- Company sponsors provide a suitable logo, accessible name, and destination
  URL. Sponsor links do not include tracking parameters.
- Recognition does not imply endorsement by Git Slop or its maintainers.
- Recognition changes are handled through normal project maintenance. Sponsors
  whose sponsorships end are removed from the active listings.
- Sponsorship provides recognition and a feedback channel. It does not include
  a support SLA, guaranteed issue priority, or roadmap control.
